# 坦克动荡 · Tank Turmoil

一款无需安装、无需联网的单文件 Canvas 坦克对战游戏。直接用浏览器打开 `index.html` 即可游玩。

## 玩法

坦克会被随机投放到一座没有出口的密闭迷宫中。所有坦克只有 1 点生命，一发命中即出局；炮弹会沿墙壁反射，而且不分敌我——包括发射者自己。

## 模式

- **本地 2P**：两名玩家在同一键盘上对战
- **1V1 人机**：玩家对战一台 AI 坦克
- **1V1V1 乱斗**：P1、P2 两名玩家与一台 AI 坦克三方混战

AI 会锁定目标、自动寻路、寻找射击线，并根据目标移动进行预判射击。

## 操作

| 玩家 | 转向 | 前进 / 后退 | 开炮 |
| --- | --- | --- | --- |
| P1 | `A` / `D` | `W` / `S` | `Space` |
| P2 | `←` / `→` | `↑` / `↓` | 右 `Ctrl` |

- `R`：重新生成迷宫并开始新一局
- 手机 / 平板：使用每名玩家对应的屏幕控制条

## 特性

- 随机生成的封闭迷宫，出口数量始终为 0
- 三种游玩模式，可随时切换迷宫尺寸（7×7 / 9×9 / 12×12）
- 炮弹沿墙面镜面反射，飞行 28 格后自动消失
- 友军伤害、自我伤害与 1 点生命
- 炮弹之间不会互相碰撞
- 回合结束显示胜负，可直接用 `R` 重新开始

## 技术说明

整个游戏都写在 `index.html` 中，使用原生 HTML、CSS、JavaScript 与 Canvas 2D，不依赖任何第三方库或外部资源。
