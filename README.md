# 坦克大战 · Tank Battle

一个用原生 HTML / CSS / JavaScript（Canvas）编写的经典坦克大战（Battle City）网页游戏，无需任何依赖，双击打开 `index.html` 即可游玩。

## 玩法

- **移动**：`WASD` 或方向键
- **射击**：`空格` 或 `J`
- **暂停**：`P`
- **静音**：`M`

消灭所有敌军坦克，同时**保护你的基地（鹰徽）**不被摧毁。基地一旦被毁，游戏立即结束。

## 特性

- 四种敌军坦克：普通、快速、火力、重装（3 血）
- 可破坏的砖墙、坚固的钢铁墙、阻挡坦克的水、藏匿坦克的草丛
- 道具：火力增强、生命 +1、护盾、全屏消灭
- 关卡递进、分数与本地最高分记录
- 粒子爆炸、音效、触屏控制

## 本地运行

直接用浏览器打开 `index.html`，或启动任意静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
