# 钢铁前线 · 坦克大战

一款无需安装、无需联网的单文件 Canvas 坦克大战游戏。直接用浏览器打开 `index.html` 即可游玩。

## 操作

- `WASD` / 方向键：移动
- `空格`：开火（按住可连射）
- `P` / `Esc`：暂停 / 继续
- `M`：静音
- 手机 / 平板：使用画面下方的方向键与 FIRE 按钮

## 玩法

驾驶主战坦克击退五道防线的敌军装甲部队。

- 砖墙可被炮弹击毁，钢墙只有满级火力才能打穿，水域无法通行，树林会遮挡视野。
- 每第 4 辆出场的敌方坦克会闪烁并携带补给，击毁后必定掉落；普通敌人也有几率掉落补给。
- 补给包括：火力升级、护盾、基地修复、全屏爆破、增援装甲。
- 基地被击毁不会直接结束战斗，但会扣除最多 1000 分，并投放一个维修补给；拾取维修补给可以重建基地。
- 装甲耗尽（初始 4 辆坦克）时才会失败；通关全部 5 个战区即为胜利。
- 本版本已下调难度：初始装甲更多、同屏敌军更少、敌方射速更慢，补给掉落率也更高。
- 最高分会自动保存在浏览器本地。

## 技术说明

整个游戏都写在 `index.html` 中，使用原生 HTML、CSS、JavaScript 与 Canvas 2D，不依赖任何第三方库或外部资源。
